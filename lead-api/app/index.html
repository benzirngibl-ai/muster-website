Auf dem iPhone zuerst zum Startbildschirm hinzufügen
  1. Diese Seite in Safari öffnen (nicht in Chrome).
  2. Unten auf das Teilen-Symbol tippen — das Quadrat mit dem Pfeil nach oben.
  3. „Zum Home-Bildschirm" wählen und bestätigen.
  4. Den neuen Anfragen-Knopf auf dem Startbildschirm antippen.
  5. Dort erscheint dieser Hinweis erneut — dann auf „Erlauben" tippen.
